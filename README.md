# Dev Patel — Portfolio

I don't wait for the world to change. I build the change.

This is the source behind **[devpatel.in](https://devpatel.in)** — my personal portfolio, built from scratch, shipped with obsession. No frameworks, no shortcuts. Just clean code, sharp design, and a story worth reading.

Founder of Navdek. BTech CS. Turning curiosity into creation.

---

## Stack

- Vanilla HTML5 · CSS3 · JavaScript (ES6+)
- Zero frameworks · Zero bundlers · Zero build step
- FormSubmit.co — contact form backend
- Netlify — hosting

---

## Features

- Custom animated cursor
- Scroll-triggered reveal animations (Intersection Observer)
- Typewriter effect with reduced-motion support
- Animated skill progress bars
- Photography carousel with touch/swipe
- Contact form with spam honeypot
- PWA manifest + service worker ready
- Full SEO — OG tags, JSON-LD Person schema, sitemap
- Security hardened — CSP, HSTS, X-Frame-Options, nosniff headers

## Run Locally

No build step — open `index.html` in any browser, or use a local server:

```bash
npx serve .
```

---

## Deploy

`netlify.toml` is pre-configured. Connect this repo to Netlify or drag the folder into the Netlify dashboard. All security headers apply automatically.
